
# 📊 Dashboard de Ventas Online - Power BI

## 📌 Descripción del Proyecto
Este proyecto consiste en el desarrollo de un dashboard interactivo en Power BI para analizar las ventas de productos en línea durante un periodo determinado.

El análisis permite identificar:
- meses con mayores y menores ventas,
- productos más vendidos,
- comportamiento de la facturación,
- composición de categorías,
- y tendencias de ventas.

---

# 🎯 Objetivos del Análisis

Responder las siguientes preguntas de negocio:

1. ¿Cuál fue el mes con mayor y menor cantidad de unidades vendidas?
2. ¿Cuál fue el mes con mayor y menor facturación?
3. ¿Cuáles fueron los 3 productos más vendidos?
4. ¿Cuántos auriculares inalámbricos se vendieron en julio y qué porcentaje representan?
5. ¿Cómo estuvieron compuestas las ventas de belleza y cuidado personal?
6. ¿Qué tendencia mostró la categoría "Hogar y jardín"?

# 📊 Principales Insights

## 📌 Ventas por mes
- Mayo fue el mes con mayor cantidad de unidades vendidas.
- Septiembre presentó el menor volumen de ventas.

## 💰 Facturación
- Mayo registró la mayor facturación.
- Junio fue el mes con menor facturación.

## 🏆 Top productos vendidos
Los productos más vendidos fueron:
1. Bicicleta de montaña
2. Gafas de sol
3. Teléfono inteligente

## 🎧 Auriculares inalámbricos
En julio se vendieron 52 unidades, representando aproximadamente el 13,16% del total de unidades vendidas ese mes.

## 💄 Belleza y cuidado personal
La categoría mostró una mayor participación de:
- Secador de cabello profesional
- Perfume para mujer
- Crema hidratante facial

## 🏡 Hogar y jardín
La facturación mostró un pico importante en mayo y una caída en septiembre.
